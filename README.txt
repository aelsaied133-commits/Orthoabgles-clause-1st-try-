ORTHOAXIS PLANNER - PWA package
1. Host this folder over HTTPS (service workers need HTTPS or localhost): GitHub Pages, Netlify, Cloudflare Pages (all free), or locally: python3 -m http.server 8000 then open http://localhost:8000
2. Open once online so the files are cached; afterwards it works offline.
3. iPad Safari: Share > Add to Home Screen. Android Chrome: menu > Install app.
4. Cases are stored in this browser's IndexedDB on this device only. Clearing site data deletes them - export backups.
5. After editing index.html, change V='orthoaxis-v1' in service-worker.js (e.g. v2) so devices refresh the cache.
